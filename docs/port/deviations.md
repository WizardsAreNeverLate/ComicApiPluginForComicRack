# Deliberate differences from the Python plugin

The maintainer decided on 2026-11-09 that the port fixes the original's bugs instead of reproducing them. Behaviour that is unusual but intended stays as it is.

Every entry in this file gives the Python behaviour, the C# behaviour, and the test that pins the C# behaviour. The oracle tests in the test project skip exactly the inputs listed here, and they skip nothing else.

Paths are relative to `comic-vine-scraper/src/py/` at v1.0.102.

## Classified as intended

These items were checked and kept. `architecture.md` gives the reason for each.

- Skip forever saves every field as the book read it. So the series, number, and year parsed from the filename go into blank fields, `ShadowVolume` and `ShadowFormat` become `Volume` and `Format`, and the Comic Vine ids are written back unchanged. An earlier note said the ids are cleared. `MergeOracleTests.PlanSkipForever_and_Apply_write_what_ComicBook_skip_forever_writes` shows they are not.
- The inferred format is always written to `Format`.
- The scrape note time (formerly deviation 10). `%X` is `HH:mm:ss` in every culture under the IronPython 2.7.4 that ComicRack ships (thread culture or `LC_TIME`), and nothing calls `setlocale`, so Python's regex finds every note Python wrote. The port writes the same text and keeps Python's regex. `KeyMarkerOracleTests.Notes_Python_wrote_under_every_culture_are_replaced_whole` pins it.
- `SCRAPE_DELAY` defaults to 1, but parsed values are clamped to 2..3600.
- Book sorting uses culture-sensitive compare.
- `UrlPathEncode` does not escape `&`, `+`, or `#`. In search terms, search cleanup removes these characters first, so users never see the difference. The port uses `Uri.EscapeDataString`. In the issue-number filter the difference is visible, so that case is bug 14.
- `associated_images` holds its `original_url` elements as direct children, as Python reads them. This was checked against the live responses for issues 37566 and 535328 (fixtures `issue-37566` and `issue-535328`), so alternate covers work in Python and need no fix.
- Python's xml2py reads an element whose only child is a string element as that string, so an `<image>` with one URL has no image URL and a `<publisher>` with only a `<name>` has no publisher. Comic Vine always sends several children there, so `ComicVineXml` keeps the rule, and the oracle checks it on the synthetic fixtures.
